Supabase en Tiempo Real (Reutilizando tu Proyecto Existente)

Auto-Sync Tiempo Real Activo

Puedes alojar esta base de datos dentro de cualquier proyecto que ya tengas en tu cuenta de Supabase sin crear un proyecto nuevo: usa únicamente una tabla aislada (public.smartpiggy_families) que no interfiere con tus demás tablas, y sincroniza cada cambio automáticamente en tiempo real por WebSocket sin necesidad de botones manuales.

Transmisión en Tiempo Real Automática: Al pegar tu Project URL y tu Anon Key de Supabase, el canal WebSocket (wss://.../realtime/v1/websocket) se conecta solo y replica cada movimiento al instante en todos los dispositivos.
SQL de 1 Tabla Aislada para tu Proyecto Existente de Supabase (No afecta otras tablas) 
create table if not exists public.smartpiggy_families (
  family_code text primary key,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.smartpiggy_families enable row level security;
create policy "smartpiggy_sync_all" on public.smartpiggy_families for all to anon, authenticated using (true) with check (true);
alter publication supabase_realtime add table public.smartpiggy_families;

Instalar SmartPiggy en tu Dispositivo

Instala SmartPiggy Cloud como una aplicación nativa a pantalla completa en tu celular, tablet o computadora:

Tu navegador permite instalación directa en 1 clic:

En Android (Chrome / Edge / Samsung Internet): 1. Toca el menú de 3 puntos (⋮) arriba a la derecha.
2. Selecciona "Instalar aplicación" o "Agregar a la pantalla principal".
En iPhone / iPad (Safari): 1. Toca el botón Compartir (cuadro con flecha hacia arriba en la barra inferior).
2. Desliza hacia abajo y toca "Agregar a inicio" (Add to Home Screen).
